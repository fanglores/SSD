# S05 - R-01 Перехват/reuse JWT/токенов через публичную поверхность может дать полный доступ.

## Контекст риска (из S04)

- **Risk-ID:** R-01 **Threat:** S (Spoofing)
- **DFD element/edge:** Edge: Internet → API (JWT, API-token)
- **NFR link (ID):** NFR-003
- **L×I (1-5):** L=4, I=4, Score=16
- **Ограничения/предпосылки:** Backend (FastAPI), REST API, стандарт JWT (RFC 7519), требования компании по сроку жизни токенов (TTL ≤ 60 мин.), нет обязательной регуляторки по PKI, SLO: доступность 99.9%, аудит по логам.

---

## Критерии и шкалы (1-5)

**Польза (чем больше - тем лучше, ↑):**

- **Security impact (↑):** насколько альтернатива снижает риск (предотвращает/обнаруживает/сдерживает).
- **Blast radius reduction (↑):** насколько сужает возможный ущерб (только один тенант/аккаунт/фича вместо всего сервиса).

**Стоимость/сложность (чем меньше - тем лучше, ↓):**

- **Complexity (↓):** сложность внедрения (код/конфиг/политики).
- **Time-to-mitigate (↓):** сколько времени до эффекта (в днях/спринтах).
- **Dependencies (↓):** внешние/внутренние зависимости (команды, провайдеры, миграции).

> Оценка **1-5**: 1 - минимально / 5 - максимально. Для «стоимостных» критериев **меньше - лучше**.

**Итоговые метрики (подсказка):**

- **Benefit = Security impact + Blast radius reduction**
- **Cost = Complexity + Time-to-mitigate + Dependencies**
- **Net = Benefit − Cost** _(чем больше, тем привлекательнее)_

## Решение (ADR candidate)

**Chosen alternative:** JWT TTL=15min + обязательный Refresh
**Почему:** Быстро даёт эффект, минимальная сложность, легко сопровождать, не требует пересборки PKI, соответствует регламентам, наиболее понятен команде.
**ADR candidate:** “JWT TTL + Refresh”
**Связки:** Risk-ID R-01, NFR-ID NFR-003, DFD Edge: Internet→API

**Следующие шаги:**

1. Уменьшить TTL для access-token до 15 минут в gateway config
2. Внедрить обязательный refresh-token поток (refresh endpoint)
3. Протестировать сценарии истечения и обновления для клиентов
4. Обновить документацию по API авторизации
5. Подготовить дашборд метрик по valid/expired токенам
