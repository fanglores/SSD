# S04 - Приоритизация рисков L×I (risk scoring template)

## Шкала L×I (1-5)

**Likelihood (вероятность):** 1 - маловероятно (редкая поверхность, сложная эксплуатация, хорошая детекция) 2 - низкая 3 - средняя 4 - высокая 5 - очень высокая (публичная поверхность, типовая уязвимость, слабая детекция)

**Impact (ущерб):** 1 - низкий (локальный эффект, без PII/денег/доступности) 2 - умеренный 3 - значимый (PII/деньги одного клиента/подсистемы) 4 - высокий (существенный ущерб/простой) 5 - критичный (массовая утечка, компрометация прав, длительный простой)

## Top-5 рисков (по Score)

- R-01 (Score 16): Перехват/reuse JWT/токенов через публичную поверхность может дать полный доступ. Обоснование: высокая вероятность и критичный ущерб.
- R-03 (Score 15): Утечка PII/email через логи, ошибки и невалидный input - массовый ущерб, ошибки происходят часто.
- R-07 (Score 15): MITM/подмена внешнего API без TLS/mTLS - ущерб по третьим сторонам, критичное последствие.
- R-02 (Score 12): DoS/flood на эндпоинты открытому API - вполне вероятно, вызывает простой всего сервиса.
- R-05 (Score 10): Кража токенов в базе, если будут храниться в plaintext - критичный ущерб, хоть поверхность не прямая.
