# Security Policy

## Reporting
- **НЕ храните** секреты в коде
- **Сообщайте** уязвимости Цатурьяну К. или Дандамаеву Г.
- **Обновляйте** ключи регулярно
- **SLA**: ответ за 24 ч, фикс за 5 дней

## Development Rules
- Используйте **синтетические данные** (без ПДн/платежек)
- Следуйте **единому формату ошибок** из README
- pre-commit хуки проверяют на секреты и проч. автоматически, поэтому запускайте перед коммитом
